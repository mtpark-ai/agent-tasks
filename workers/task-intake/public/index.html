ONE LOCAL COMMAND

完成高权限初始化

在你的电脑运行

Cloudflare 已把模板复制到你的 GitHub 账号。粘贴那个新仓库的 clone URL，页面会生成初始化命令。

目标任务仓库默认就是这个仓库。若它是公开仓库，命令会要求你再次明确确认。

macOS / Linux / Windows PowerShell 
# 先粘贴上方 GitHub 仓库 URL
命令会做什么？
  • 检查并确认当前 Cloudflare 账号。
  • 隐藏输入 GitHub fine-grained PAT，并验证仓库可见性。
  • 应用 D1 migrations。
  • 生成并写入 ADMIN_TOKEN 与 GITHUB_TOKEN Worker Secrets。
  • 初始化固定 GitHub labels，并创建首个低权限 iPhone Device Token。
  • 将 Token 保存到本机被 Git 忽略的 .task-intake.local.json。

FINAL STEP

绑定 iPhone Action Button

  1. 在 iPhone 导入并试运行 Shortcut。
  2. 打开“设置” → “操作按钮”。
  3. 选择“快捷指令”，再选择 Agent Tasks。
  4. 按住按钮，说出任务；编辑听写结果并确认提交。
Agent Tasks 所有任务默认只进入待审核 Issue，不自动批准或执行。

Issues Read and write Metadata Read Account permissions 0

不要勾选截图里的 “Agent tasks”。它与 GitHub Issue 不是同一个权限；也不要添加 Contents、Administration、Actions、Secrets。

GitHub 会为仓库令牌保留只读 Metadata；预填链接也显式带上它。唯一需要手动选择的是具体仓库。

技术人员查看：这条命令会做什么
  • 确认当前 Cloudflare 账号，未登录时打开浏览器完成 OAuth 登录。
  • 验证最小权限 GitHub fine-grained PAT 和仓库可见性。
  • 应用 D1 数据库迁移并写入 Worker Secrets。
  • 初始化固定任务标签，并创建低权限 iPhone Device Token。
  • 把管理员凭据和设备凭据保存在本机被 Git 忽略的文件中。

遇到问题

常见问题

运行命令后显示未登录 Cloudflare

新版设置流程会自动打开浏览器登录。完成登录后回到终端，流程会继续。

GitHub 授权码粘贴后看不到字符

这是正常的安全行为。终端会隐藏输入内容，粘贴后直接按回车即可。

GitHub 页面里找不到正确权限

在 Repository permissions 中搜索 Issues 并选 Read and write。不要选择名字相近的 Agent tasks。Metadata 保持 Read，Account permissions 保持 0。

GitHub 授权码显示 Pending

组织可能要求管理员批准 fine-grained token。等待组织管理员批准后，再把授权码粘贴到终端。

页面一直显示“等待电脑设置”

先确认终端最后显示“设置完成”，然后点击本页的“重新检查状态”。若中途报错，重新运行同一段命令即可。

为什么网页不直接显示 iPhone 配置码？

为了避免低权限配置码被公开页面、浏览器缓存或截图意外泄露，它只在你的电脑终端和本机配置文件中显示。
